# Weekly feature contract (`weekly-v1`)

Inputs are raw weekly records for **one student in one course**. Weeks start on Monday.
The cutoff is the record's `week_start` date: a record is eligible only when its date is
on/before `as_of_date`. Weekly aggregates cannot reconstruct intraweek events or earlier
versions of a subsequently corrected record. Persisted prediction snapshots will retain
the exact input values used at prediction time.

The window contains at most eight calendar weeks ending in the week containing `as_of_date`.
Unknown values stay `None`; zero is used only when actually observed. No interpolation,
forward filling, sentiment analysis, or future observations are used. Current features are
missing if the requested week has no record; an older record does not become the current week.

| Feature | Definition and minimum data |
|---|---|
| attendance_percent | Current `100 * attended / held`; positive denominator required |
| avg_score | Current recorded assessment average; backend does not invent individual marks |
| score_std / score_volatility | Population standard deviation of observed weekly assessment averages; at least two weeks |
| *_3wk_avg | Arithmetic mean for current week and two preceding calendar weeks; all three values required |
| *_change_4wk | Current value minus value exactly 28 days earlier; both endpoints required |
| *_volatility | Population standard deviation over observed values in the eight-week window; at least two observations |
| *_slope | Ordinary least-squares slope using actual elapsed weeks; at least two observations |
| on_time_submissions | Current assignment count minus late submissions when both are known |
| last_minute_submission_rate | Current `100 * last_minute_submissions / assignment_count`; positive denominator |
| participation_rate | Current `100 * participation_count / participation_opportunities`; positive denominator |
| quiz_score_volatility | Population standard deviation of observed weekly quiz averages; at least two weeks |
| late_submission_streak | Trailing consecutive observed weeks with late submissions > 0 |
| low_score_streak | Trailing consecutive observed weeks with assessment average < 50 |
| engagement_score | Equal-weight mean of current attendance, participation, and on-time submission percentages; all three required |
| academic_consistency | `max(0, 100 - 2 * score_std)`; at least three observed assessment averages |

Temporal attendance, score and study-hours features share the same calendar-window rules.
Streaks are bounded by the observed window; a missing week/value inside a candidate streak
returns `None`, and does not bridge the gap. A current observed nonqualifying value gives 0.
Remaining direct features copy the current week's raw counts/measurements. `sentiment_score`
remains missing because no separate classifier is present. PII and check-in text are excluded.

These are explicit operational definitions, not assertions that the supplied synthetic CSV
was generated by these formulas. In particular, dispersion of weekly averages is different
from dispersion of individual assessments or simultaneous subject marks. Any future change
to formulas must increment the feature version. Metadata records window dates, weeks used,
history count and score observation count.
